= Getting Started with signal-cli (Rust)

== 1. Install

Install the Rust toolchain, then:

[source,bash]
----
git clone https://github.com/wnoronha/signal-cli
cd signal-cli
make install
----

This puts the binary in `~/.local/bin/signal-cli`.

== 2. Set up an account

Link as a secondary device, or register a new number.

=== Option A: Link (use your existing account)

[source,bash]
----
signal-cli link
----

A QR code prints in the terminal. Scan it with Signal on your phone (Settings → Linked Devices). If you scan from another machine, use the printed `sgnl://` URL.

The CLI saves the account database automatically.

=== Option B: Register (use a new number)

[source,bash]
----
signal-cli -a +1234567890 register
----

Enter the SMS code when asked. If the server asks for a captcha, get a token at `https://signalcaptchas.org/registration/generate.html` and pass `--captcha <token>`.

Note: the standalone `verify` command does not work. Verification happens inside `register`.

== 3. Send a message

[source,bash]
----
signal-cli -a +1234567890 send -m "Hello" +0987654321
signal-cli -a +1234567890 send -m "Photo" -a ./photo.jpg +0987654321
----

If you have one account, you can omit `-a`. With more than one account, `-a` is required.

== 4. Receive messages

[source,bash]
----
signal-cli -a +1234567890 receive
----

Add `--output json` for machine-readable output.

== 5. Use the daemon

Start the daemon on a UNIX socket:

[source,bash]
----
signal-cli -a +1234567890 daemon --socket /tmp/signal.sock
----

Send a request (example with `socat`):

[source,bash]
----
echo '{"jsonrpc":"2.0","method":"listGroups","id":1}' | socat - UNIX-CONNECT:/tmp/signal.sock
----

HTTP mode (default bind `127.0.0.1:8080` when `--http` has no value):

[source,bash]
----
signal-cli -a +1234567890 daemon --http
curl -s http://127.0.0.1:8080/api/v1/check
curl -N http://127.0.0.1:8080/api/v1/events
----

See link:daemon-rust-port.adoc[daemon Rust port notes] for endpoints and unsupported flags.

== 6. Test scripts

`scripts/` has Python tools to test the daemon:

[source,bash]
----
python3 scripts/signal-cli-test.py --socket /tmp/signal.sock --auto-reply
----
