= Command status (Rust port)

This matrix tracks parity with https://github.com/AsamK/signal-cli[AsamK/signal-cli].

== Status values

* *Implemented* — works with `presage` in this repo
* *Stub* — command exists; fails with library limitation or not implemented
* *Partial* — subset of flags or behavior

== Note prefixes

Notes use the same labels as link:../CHANGELOG.md[CHANGELOG.md]:

* *CLI* — command-line behavior, flags, exit codes
* *JSON-RPC* — daemon methods and RPC errors
* *Daemon* — long-lived daemon transport and session rules
* *Compat* — Java signal-cli flags accepted but not implemented
