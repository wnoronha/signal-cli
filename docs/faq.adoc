= Frequently Asked Questions (FAQ)

== Linking

=== Can I link more than one device to the same account?
Yes. Signal allows more than one secondary device per phone account. Run `link` for each device.

== Messaging

=== Why does send fail with a phone number?
The recipient may hide their number (Signal privacy settings). Then the number does not resolve. Use the recipient UUID instead. To map a UUID to a number, run `updateContact <UUID> --phone-number <NUMBER>`.

=== How do I send a message to myself?
Use the `--note-to-self` flag with `send`.

== Errors

=== Why do I see "Library limitation" errors?
Some commands need functions that `presage` does not expose yet (for example group admin). These commands are stubs. They return an error that says so.

=== Where is my account data?
SQLite files in `~/.local/share/signal-cli/`, named `+<phone>.db`. Use `--config <path>` to change the location.

=== How do I get more logs?
Add `-v` (or `--verbose`) to any command.
