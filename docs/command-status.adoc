= Command status (Rust port)

This matrix tracks parity with https://github.com/AsamK/signal-cli[AsamK/signal-cli].
Status values:

* *Implemented* — works via `presage` in this repo
* *Stub* — CLI/RPC exist; returns `Library limitation` or `Not implemented`
* *Partial* — subset of flags or behavior

== Account

|===
| Command | Status | Notes

| `register`, `link` | Implemented | Verification is interactive during `register`
| `verify` | Partial | Use `register` flow; subcommand prints guidance only
| `listAccounts` | Implemented |
| `deleteLocalAccountData` | Implemented | Does not unregister on server
| `unregister`, `setPin`, `removePin` | Stub | Exits non-zero; `Not implemented` / JSON error
| `updateAccount`, `updateConfiguration`, change number | Stub | Exits non-zero; account settings not in presage API
|===

== Messaging

|===
| Command | Status | Notes

| `send`, `receive` | Implemented | Many `send` flags ignored (quotes, stories, etc.)
| `sendReaction`, `sendReceipt`, `sendTyping`, `remoteDelete` | Implemented |
| `getAttachment`, `getAvatar` | Implemented |
| Polls, pin messages, payments | Stub | JSON-RPC returns library limitation
|===

== Groups & contacts

|===
| Command | Status | Notes

| `listGroups` | Implemented | `joinGroup` / `updateGroup` / `quitGroup` stubbed (non-zero exit)
| `listContacts`, `updateContact`, `updateProfile` | Implemented / partial |
| `removeContact`, `block`, `unblock` | Stub |
| `listIdentities`, `trust` | Stub |
|===

== Devices & stickers

|===

|===
